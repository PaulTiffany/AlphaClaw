# Start Here: Your First Open-Source Wiki Page

**Goal: make two Wiki pages.**

You do not need to know how to program. You do not need to use a command line.

## What is open source?

Open source means a project is shared so other people can see it, learn from it, use it, change it, and share it under clear rules.

Those rules are called a **license**.

AlphaClaw uses the **MIT License** for its original work.

In simple terms, MIT says people may use, copy, change, and share the work, including for business. Copies or large parts of the work must keep the MIT copyright and permission notice.

Other common open-source licenses include:

- **Apache 2.0** — broad permission, with added patent terms.
- **GPL** — shared changes usually need to stay under the GPL when distributed.
- **BSD** — broad permission, similar in spirit to MIT.

You do not need to choose a license here. AlphaClaw already uses MIT. The repository `LICENSE` file gives the exact terms.

## Before you save

This Wiki is public.

Only share work you have the right to share. Do not post passwords, private messages, API keys, private personal information, or confidential material.

If you use an AI writing helper such as Gemini, read the result before you save it. Make sure it still says what **you** mean. You are responsible for the page you publish.

AlphaClaw accepts Wiki contributions under the MIT License. GitHub keeps a public history of the account that changed each page.

## Make your first page

1. Open the AlphaClaw **Wiki**.
2. Choose **New Page**.
3. Give your page a short title.
4. Write a few sentences about something useful to the project.
5. If you want help, ask Gemini:

   > Help me turn these thoughts into a short, clear GitHub Wiki page. Keep my meaning. Use simple language. Do not add facts I did not give you.

6. Read the page yourself.
7. Check again that it contains nothing private.
8. Choose **Save Page**.

You just made an open-source contribution. GitHub saved your page and its history.
