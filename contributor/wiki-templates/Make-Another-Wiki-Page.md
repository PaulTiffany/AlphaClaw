# Make Another Wiki Page

Use this page any time you want to contribute again.

1. Open the AlphaClaw **Wiki**.
2. Choose **New Page**.
3. Give the page a short title.
4. Write what you want to share.
5. If useful, ask Gemini:

   > Help me turn these thoughts into a short, clear GitHub Wiki page. Keep my meaning. Use simple language. Do not add facts I did not give you.

6. Read the page yourself. Make sure it still says what **you** mean.
7. Check that it contains nothing private.
8. Choose **Save Page**.

That is enough. You can come back to this page whenever you want to make another Wiki page.
